# 百度网盘

通过 POCO 连接器调用百度网盘官方 MCP，浏览、检索和管理用户的云端文件。当前能力包括目录与分类浏览、关键词与语义检索、文件元信息和容量查询、文件整理、创建分享链接，以及通过 URL 转存文件。

用户需在 POCO 授权表单中填写 Access Token，参见[授权说明](references/setup.md)。只使用 POCO 当前发现且允许的工具，参数以工具返回的 Schema 为准，不猜测工具名、文件 ID 或可选参数。

## 能力边界

当前连接器支持：

- 浏览指定目录下的全部文件，或按文档、图片、视频分类查看。
- 按文件名关键词搜索。
- 使用自然语言进行语义检索；目录、文件类型、扩展名和数量筛选以当前工具 Schema 支持的参数为准。
- 如果当前 Schema 提供对应搜索来源，可在图片 OCR 文字、文档正文中检索，或对图片、文档、视频和音频内容进行语义检索。
- 查询文件元信息、用户基本信息和网盘空间使用情况。
- 新建文件夹，复制、移动和重命名文件。
- 为一个或多个文件创建带有效期和提取码的分享链接。
- 通过可直接下载的 URL 将文件转存到网盘。

当前工具集中未提供：

- 文本内容保存：官方文档重复使用了 URL 转存工具名，实际文本工具名称及 Schema 尚未核验，本版本未开放。
- 将网盘文件或文件夹下载到本地。
- 直接上传用户设备上的任意本地文件。
- 删除网盘文件或文件夹。
- 将分享链接直接发送给某个联系人；连接器只能创建分享链接，由用户自行发送。

不要把“URL 转存”描述为完整的本地文件上传能力，也不要承诺文本保存、下载或删除操作。

## 调用原则

- 涉及百度网盘时，优先使用本连接器提供的 MCP 工具，不要用本地文件系统命令代替网盘操作。
- 目标文件、目录或路径不明确时，先浏览或搜索，再执行后续操作。
- 执行新建、复制、移动、重命名、转存或创建分享链接等写操作前，确认目标对象、目标目录、文件名及冲突处理方式，并完成 POCO 的操作确认。
- 移动、重命名和覆盖可能改变用户现有文件结构；未获得明确授权时，不使用覆盖策略。
- 用户只要求查找或查看时，保持只读，不顺带执行整理、分享或上传操作。
- 工具要求绝对路径时使用以 `/` 开头的网盘路径；路径含中文时，按工具参数说明进行 URL 编码。
- 搜索结果可能较多时使用分页或限制返回数量，并向用户说明结果范围。
- 所有写操作禁止自动重试；超时或断线时，先通过只读查询核对结果，再由用户决定是否重新提交。
- 创建目录、复制、移动和重命名接口支持覆盖，POCO 统一将这些接口按破坏性操作确认；这不代表已允许采用覆盖参数。

## 工具选择

| 能力 | 官方工具名 |
| --- | --- |
| 目录与分类浏览 | `file_list`、`file_doc_list`、`file_image_list`、`file_video_list` |
| 文件元信息 | `file_meta` |
| 关键词与语义检索 | `file_keyword_search`、`file_semantics_search` |
| 账号与容量 | `user_info`、`get_quota` |
| 新建目录与文件整理 | `make_dir`、`file_copy`、`file_move`、`file_rename` |
| URL 转存 | `file_upload_by_url` |
| 分享链接 | `file_sharelink_set` |

工具白名单依据[固定提交的官方说明](references/upstream/README.md)。该说明包含本连接器未开放的删除、本地上传和文本保存内容；实际可用范围以上表及 POCO 工具发现结果为准。

### 浏览与查询

- 查看目录内容：使用通用文件列表。
- 只查看文档、图片或视频：使用对应的分类列表。
- 查询文件详情：先从列表或搜索结果取得文件 ID，再查询元信息；单次最多查询 10 个文件 ID。
- 查询网盘容量：使用空间配额查询。
- 查询账号基础信息：使用用户信息查询。

### 搜索

- 用户给出明确文件名关键词时，优先使用文件名关键词搜索。
- 用户使用自然语言描述内容、主题、场景、时间或地点时，优先使用语义检索。
- 用户要求搜索图片文字、文档正文或按画面、音视频内容检索时，先核对 Schema 是否支持对应搜索来源；未提供时应说明限制。
- 用户指定文件类型或后缀时，若工具支持分类或扩展名参数，再设置过滤条件，减少无关结果。

### 文件管理

- 新建文件夹前确认完整目标路径；同名冲突时，除非用户另有要求，优先采用自动重命名而非覆盖。
- 复制、移动和重命名时，先确认源文件绝对路径、目标目录和目标名称。
- 遇到同名文件时，向用户说明可选策略：失败、生成副本名、覆盖或跳过。默认优先选择生成副本名，避免覆盖已有文件。
- 工具仅返回异步任务 ID 时，只能说明操作已受理；需要通过后续只读查询确认文件状态，不能直接声称整理已完成。

### 分享

- 创建分享链接前确认待分享文件、有效期和 4 位提取码；备注仅在工具 Schema 支持时设置。
- 提取码只能由数字和小写字母组成，长度为 4 位。
- 创建成功后向用户返回分享链接、有效期和提取码，但不要声称已发送给任何联系人。

### URL 转存

- 用户未指定目录时，工具默认保存到 `/来自：mcp_server`；执行前应告知用户默认位置，或询问其期望目录。
- 用户未指定文件名时，URL 转存工具通常从链接提取文件名并添加 mcp 标识；执行前核对当前 Schema 的默认行为，优先确认目标文件名。
- 用户提供可直接下载的文件链接并要求保存到网盘时，使用 URL 转存。
- URL 不是直接下载地址、需要登录或访问受限时，不保证转存成功，应向用户说明限制。
- 用户要求保存文字或会议纪要时，说明本版本尚未开放文本保存，不用 URL 转存工具代替文本上传，不通过其他接口绕过限制。

## 使用示例

- 查看我百度网盘根目录下的文件，并告诉我还剩多少可用空间。
- 列出「项目资料」文件夹里的所有文档。
- 从文件名、文档正文和图片文字中搜索与「项目合同」相关的文件。
- 找出网盘里与海边日落相关的图片和视频。
- 搜索最近整理的 AIGC 研究资料，只返回 PDF 和 DOCX 文件。
- 新建一个「AIGC 调研资料」文件夹，把相关文件复制进去。
- 把「旧项目/周报.docx」移动到「归档/2026」，遇到同名文件时跳过。
- 将「最终方案-v3.docx」重命名为「最终方案.docx」。
- 为「周报.docx」创建一个有效期 7 天、带 4 位提取码的分享链接。
- 把这个可下载链接中的文件转存到百度网盘的「参考资料」文件夹。

## 错误处理

- 认证失败：当返回 HTTP 401/403、Access Token 无效或过期等错误时，提示用户在连接器管理中重新连接百度网盘；如需重新获取凭据，可参考百度网盘开放平台文档：<https://pan.baidu.com/union/doc/Wm9sl0i0j>。
- 路径错误：确认路径以 `/` 开头，并按工具要求对包含中文的路径进行 URL 编码。
- 文件不存在：先重新浏览父目录或搜索文件名，避免基于猜测继续执行。
- 同名冲突：不要擅自覆盖，向用户说明冲突并确认使用生成副本名、覆盖、跳过或失败策略。
- 分享失败：检查文件 ID、有效期和提取码格式；文件 ID 列表必须符合工具要求的严格 JSON 字符串格式。
- 转存失败：检查 URL 是否可公开访问并可直接下载；若链接需要登录、验证码或临时授权，告知用户当前接口可能无法转存。
- 语义检索无结果：如实说明结果范围，由用户决定是否调整描述、搜索来源或筛选条件；不自动改为其他检索方式。

## 安全说明

- Access Token 由 POCO 管理，Provider 仅在连接官方 SSE 服务时通过 URL 参数传递；不要把凭据填入工具参数或发到对话中。
- 禁止在对话、日志或输出文件中展示完整的 Access Token。
- 未经用户明确确认，不覆盖已有文件，不移动或重命名重要文件，不创建公开分享链接。
- 分享链接、提取码和文件路径可能包含敏感信息，只向当前用户展示，不主动传播给第三方。

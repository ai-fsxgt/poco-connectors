# 百度网盘授权与使用

## 连接账号

1. 按[百度网盘开放平台接入授权](https://pan.baidu.com/union/doc/Wm9sl0i0j)取得当前用户的 Access Token。[官方 MCP 说明](https://github.com/baidu-netdisk/mcp)包含企业接入流程和个人体验说明；官方将个人体验标为临时测试用途，正式使用应按开放平台要求申请自己的应用。
2. 管理员安装连接器，分配 `feature.connector.baidu-netdisk` 权限并发布。此包没有管理员配置项。
3. 用户在 POCO 连接器页面连接“百度网盘”，将令牌填入 Access Token 密码字段。只填写令牌本身，不要填写完整授权 URL、`Bearer` 前缀或带令牌的 MCP 地址。
4. POCO 会连接官方 SSE 服务，完成 MCP 初始化和工具发现。只有成功取得白名单中的工具，授权才会完成。然后可用“查询网盘容量”或“查看根目录”进行只读验收。

本连接器采用用户手动提供 Token 的授权方式，不自动执行 OAuth 跳转、令牌刷新或远端撤销。Token 过期或授权范围变化后，按官方流程取得新 Token，在 POCO 中重新授权。需要解除百度侧授权时，使用官方说明中的[授权管理](https://passport.baidu.com/v6/appAuthority)入口。

## 工具与参数

连接器只开放 15 个已明确命名的远程工具：9 个只读工具、2 个写入工具、4 个支持覆盖的文件管理工具。工具名称保留官方命名；参数 Schema、描述和结果来自实际授权后的远程服务。

创建目录、复制、移动、重命名可能覆盖现有对象，因此统一按破坏性操作确认。URL 转存和创建分享链接按写入操作确认。所有非只读操作禁止自动重试。确认请求绑定工具及完整参数，修改参数后需重新确认。需要确认的操作只能在 POCO 即时交互任务中执行。

不开放文件删除、本地上传和本地下载。原 Skill 提到文本保存，但固定提交的官方说明将其工具名重复写成 `file_upload_by_url`；当前未开放独立文本保存工具，不推测名称或参数，也不添加其他接口作为替代。后续应先通过有效授权获取实际目录，再核对文本工具名、Schema 和风险并更新包版本。

目录、中文路径、分页、文件 ID、筛选条件和分享参数均以当前工具 Schema 为准。源 Skill 中的 OCR、正文检索、文件类型和扩展名筛选，只有对应参数实际存在时才能使用。返回异步任务 ID 表示已受理，应查询文件状态确认最终结果。

## 运行方式与限制

Provider 使用 POCO 已提供的 Python 3.12、标准库和 `httpx`，连接固定地址 `https://mcp-pan.baidu.com/sse`。POCO 原生 MCP 的凭据绑定仅支持请求头，百度官方接入需要 `access_token` 查询参数，因此由包内 Provider 负责 SSE 接入。无需安装依赖或运行本地常驻服务。

每次发现或调用都会创建独立会话；调用前重新检查工具是否在白名单、是否仍然存在，以及风险标注是否与包内策略冲突。POCO 负责 Schema 校验和消费一次性操作确认，Provider 不接受由调用方降低风险的入口。

程序总执行时间限制为 25 秒，低于 POCO 的 30 秒运行上限；输出遵循 POCO 的 1 MiB 上限。工具本身已执行但响应超时、断线或过大时，结果可能未知，应先通过只读查询确认，不应立即重新执行写操作。查询大量文件时显式分页或缩小范围。

Provider 不输出包含 Token 的请求 URL 或原始 HTTP 异常。令牌只通过授权协议交给 POCO 保管，不应出现在聊天、包文件或操作参数中。

## 验收状态

迁移期间已验证未带 Token 的官方 SSE 初始化，以及无效 Token 被服务拒绝；未使用真实账号，真实授权成功、授权后的工具目录、只读查询、文件整理、URL 转存和分享均待验收。不要把握手成功或无效 Token 校验当成真实账号验收通过。

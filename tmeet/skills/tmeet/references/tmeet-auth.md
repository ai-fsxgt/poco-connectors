# 腾讯会议连接器认证

Poco 连接器通过 Provider 执行腾讯会议 OAuth 设备授权，不需要安装 CLI，也不会把令牌写入本机文件。

连接流程如下：

1. 在连接器页面发起授权，Provider 生成一次性授权 URL。
2. 在浏览器打开授权 URL，并完成腾讯会议授权。
3. 返回 Poco 后完成授权确认，Provider 轮询获取访问令牌。

连接器会保存访问令牌、刷新令牌、Open ID 和 SDK ID，并在访问令牌临近过期时自动刷新。对话中不得展示任何令牌字段。

如果授权失败或刷新令牌失效，请使用连接器页面的“重新授权”。连接器不提供源 CLI 的本地 `auth status`、`auth logout` 命令；连接状态和凭据清理由 Poco 连接管理页面负责。

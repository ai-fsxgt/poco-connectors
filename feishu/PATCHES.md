# Poco 适配说明

上游版本：`larksuite/cli v1.0.95`

- 官方 Linux amd64 二进制和 API 目录分片均未修改；产品 Skills 仅删除连接器未暴露能力的说明。
- 未收录需要常驻事件进程的 `lark-event` Skill 与 `event` 命令，也未收录仅支持应用身份的 `lark-vc-agent` Skill。
- 未暴露依赖持久化本地项目、Git 凭据或插件状态的 `apps` 命令。
- 网页 OAuth 单次最多申请 200 个权限。连接器只接受同版本官方 `scopes.json` 发布的用户权限，并从实际命令元数据生成恰好 200 个授权范围。
- 为满足权限上限，连接器不暴露日历容器创建、删除、更新，电子表格元数据读取、更新，以及入群申请、群发言权限和群个人设置更新这 10 个边缘底层接口。
- `vc +meeting-screenshot` 依赖普通自建应用不可配置的会中实时权限，因此不暴露该命令；历史会议、录制、妙记和智能纪要查询不受影响。
- 按上游批量授权策略排除 `im:message.send_as_user`；因此不暴露消息发送、消息回复和邮件分享到聊天三个依赖该权限的快捷命令。
- Poco Provider 负责注入用户 OAuth 凭据、限制文件路径、映射风险等级和转换协议响应。

# IMA 知识库使用指南

通过 IMA 连接器检索用户已授权的私人知识库。当前连接器只提供知识库读取能力，所有凭据由 POCO 管理。

## 工具选择

| 用户意图 | 工具 | 使用方式 |
| --- | --- | --- |
| 查看有哪些知识库 | `get_knowledge_base_list` | 先取得知识库名称与 ID，再继续检索 |
| 搜索知识库内容 | `search_knowledge` | 传入目标 `knowledge_base_id` 和查询关键词 |
| 浏览知识库文件 | `get_knowledge_list` | 传入目标 `knowledge_base_id`，按返回游标继续分页 |
| 阅读文件原文 | `fetch_media_content` | 使用搜索或列表结果中的 `media_id` 获取内容 |

用户只提供知识库名称时，先用 `get_knowledge_base_list` 定位唯一目标。存在多个同名或相近结果时，展示名称让用户选择，不要自行猜测。

需要回答基于资料内容的问题时，先用 `search_knowledge` 找到相关条目，再对必要条目调用 `fetch_media_content`。搜索结果已足够回答时，不要读取无关文件。

## 结果处理

- 面向用户使用知识库名称和文件标题，不主动展示 `knowledge_base_id`、`media_id` 等内部 ID。
- 引用资料时说明来源文件；内容不足时明确说明，不补写未读取的信息。
- 群聊场景只展示完成任务所需的最少内容，避免泄露私人知识库全文。
- 分页结果不足时使用上游返回的游标继续读取，直到找到答案或没有更多结果。
- 授权失败时提示用户重新授权；限频时停止请求并说明稍后重试。

## 不支持的操作

当前连接器不提供笔记创建或追加、知识库上传、网页导入、文件删除和权限修改。遇到这些需求时说明当前连接器不支持，不要执行示例 Skill 中的 OpenAPI、Node.js 或 COS 上传脚本。
